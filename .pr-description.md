## Security Summary

- **No SQL injection**: All DB ops use stored procedures via `CommandType.StoredProcedure` + parameterized `AddWithValue`. Zero `CommandType.Text` usage.
- **No hardcoded secrets**: Connection strings use `Authentication=Active Directory Managed Identity` - no passwords anywhere.
- **XSS prevention**: Chat UI `formatMessage()` calls `escapeHtml()` (DOM text node method) before `innerHTML` assignment.
- **Managed Identity only**: No service principal secrets or passwords in any config files.
- **HTTPS only**: App Service configured with `httpsOnly: true`, `minTlsVersion: 1.2`.
- **No known CVEs**: All NuGet packages (Azure.Identity 1.13.2, Azure.AI.OpenAI 2.1.0, Microsoft.Data.SqlClient 5.2.2) are current stable versions.
